# 话题探测方法论

> 来源：天诺老吴 AI 提示词（话题探测器）+ 赛道关键词组合选题指令，已清洗。

## 核心原理：从产品跳到人

爆款短视频的根基是**洞察人性**——对人和人性的理解。拿到一个产品，**不要停留在物理属性**，要立刻跳到产品背后所连接的"人"的生活、情感、关系和社会现象。

### "纸巾"案例演示

普通产品"纸巾"，物理属性只有柔软、吸水。如果一来就讲纸巾多好——这是硬广，观众不愿意看。要抓住注意力，必须让开头戳中用户的好奇心、情感共鸣。

启动多个**话题探测器**，从产品跳到生活百态：

| 探测器维度 | 纸巾的话题延展示例 | 戳中什么 |
|---|---|---|
| **① 个体生活** | "公厕里的卷纸到底有多脏？" | 卫生焦虑 |
| 个体生活·习惯 | "身上带纸的男人一般都是渣男？" | 挑战传统认知 |
| 个体生活·消费 | "一块两块的卷纸和 80 块的到底差在哪？" | 选择困难 + 好奇心 |
| **② 两性/家庭** | "一个男人从来不往家里买纸，说明他根本没把家当回事？" | 家庭责任、情感投入 |
| 两性/家庭 | "如果你家 1/3 的纸都用来擦眼泪，要不离了吧！" | 夸张化情感争议 |
| **③ 社会/文化** | "到底印度人是用手指还是用纸巾擦的？" | 文化猎奇、地域差异 |
| 社会/职场 | "如果公司卫生间的纸都是 XX 牌子，说明这公司效益一定好？" | 职场观察、阶层象征 |
| **④ 时间/记忆** | "小时候农村爸妈用的那种纸到现在还能买着吗？" | 怀旧、时代变迁 |
| 时间/宏观 | "一个女人一生到底要用多少纸？" | 宏观数据、引发感慨 |
| **⑤ 名人/事件** | 用名人使用场景切入 | 借势流量 |

**5 秒完播率双问**：每条话题要经得起两个检验——
1. "这跟我有什么关系？"
2. "看完我能得到什么？"

## 通用话题提示词模板

适用于任何产品，让 AI 帮你做话题探测：

```
你是爆款短视频话题探测器。我现在给你一个产品名称，请你写出 10 个关于这个产品的爆款短视频话题。

要求：
1. 不要停留在产品的物理属性（功能、材质），要跳到产品背后连接的"人"——生活、情感、关系、社会现象。
2. 同时启动多个话题探测器：个体生活、两性/家庭、社会/文化现象、时间/记忆、名人/事件。
3. 每个话题都要能回答两个问题："这跟我有什么关系？" + "看完我能得到什么？"
4. 话题要能戳中：卫生焦虑 / 选择困难 / 情感争议 / 文化猎奇 / 怀旧 / 好奇心 等人性点。
5. 话题可以夸张、可以挑战认知、可以引发争议，但要能引发共鸣或讨论。

请像这样输出（以"纸巾"为例的风格）：
- 话题
- 戳中什么（一句话说明它为什么能爆）

产品名称：[填入产品]
```

## 赛道关键词组合选题

另一种选题思路：**用关键词矩阵组合出选题**，适合明确赛道后系统化产出。

### 选题步骤（严格分步，每步询问是否继续）

**第 1 步**：引导用户提供**赛道类别**（如美妆、母婴、职场）。

**第 2 步**：根据赛道，输出三类关键词各 5 个（要求是网络高频词、能代表赛道特点）：
```
[客户类别]：什么样的人
[用户痛点]：他们烦恼什么
[使用场景]：什么时候用
```

**第 3 步**：针对以上关键词组合，生成 **10 个赛道选题**。要求：
- 选题中关键词加粗标注
- 表述有吸引力、醒目、通俗易懂
- 带情绪化元素

**第 4 步**：根据用户反馈进一步优化选题，确保具备吸引力和实用性。

### 硬约束
- 敏感词、限制词用拼音或 emoji 代替。
- 忠于选题核心内容，不允许杜撰和随意联想。
- 严格分步执行，**不允许一次性完成所有步骤**，每步结束询问用户是否进行下一步。
- 熟悉各平台的规则和特点（抖音/小红书/快手/视频号/B站/公众号/头条号）。

## 选题校验清单（产出前自检）

每个选题在交付前，过一遍这 4 个问题：

1. **客资导向**：这个选题能吸引到精准目标客户吗？还是泛流量？
2. **人性洞察**：它戳中了人性的哪个点（焦虑/好奇/争议/共鸣/猎奇）？
3. **平台匹配**：它适合在哪个平台发？符合该平台调性吗？
4. **可执行性**：能落地成具体内容吗？素材从哪来？

四个都能过，才是合格的获客选题。
